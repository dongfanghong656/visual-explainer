# SPEC-0004 — Public contract enforcement and trusted server adapters

- Status: IMPLEMENTED_STAGING
- Public enforcement: 1.0.0
- Contract protocol: 2.4.0
- Requirements: REQ-0001–REQ-0007
- Runtime: `plugins/visual-explainer/task-proof/contract-public-enforcement.mjs`

## Architecture

```text
explicitly classified Task Proof MCP tool
  -> frozen Task Contract validation
  -> contract-bound Claim
  -> reviewer-owned authority and evidence collection
  -> immutable server-owned adapter registry
  -> computeStrictContractGate
  -> contractGate plus non-secret adapter manifest
```

## Invariants

1. Claimant output is always `UNVERIFIED`.
2. Contract-free Claim/Review requests fail schema validation.
3. The Review path requires the exact authority receipt set and reviewer attestation.
4. Authority, evidence, named-check, and lifecycle verifiers are resolved from in-process function factories, never request JSON.
5. A missing adapter identity fails closed.
6. Every public `task_proof_*` tool must have an explicit reviewed classification before registration.
7. npm-linked execution resolves the server's real filesystem path before deciding whether to start the stdio server.

## Boundary

The built-in registry supports repository-file authority and repository-owned evidence/lifecycle checks. User-message, GitHub Issue, release-registry, signature, hardware, scientific, production, and user-outcome authority remain unsupported. Local npm-link deployment is not npm publication or release.
