# SPEC-0003 — Task Contract Authority Protocol 2.4

- Status: ACCEPTED_CURRENT_STAGING
- Protocol: 2.4.0
- Authority receipt: 1.4.0
- Requirements: REQ-0006 and REQ-0007
- Runtime: `plugins/visual-explainer/task-proof/contract-authority.mjs`
- Portable schema: `plugins/visual-explainer/task-proof/task-contract.schema.json`

## Architecture

```text
Authority sources
  -> source requirements and coverage
  -> frozen Task Contract
  -> Author Claim
  -> reviewer-owned authority receipt set
  -> complete Review
  -> trusted evidence, named-check, and lifecycle verifiers
  -> minimum final gate
```

## Final gate

```text
minimum(
  verified evidence,
  verified authority,
  source coverage,
  contract policy,
  reviewer procedure,
  verified named checks,
  contract lifecycle,
  verified artifact lifecycle
)
```

Missing independent inputs cap the result at INCONCLUSIVE. Digest, identity, chronology, policy, source, or trusted-verifier rejection produces FAIL. Explicit exclusions or R1 review cap the result at PASS_WITH_LIMITS. Supersession produces STALE.

## Boundary

This specification describes the isolated contract core. It is not a claim that all existing public MCP and Skill entrypoints already enforce the contract.
