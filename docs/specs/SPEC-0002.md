# SPEC-0002 — Canonical strict runtime and evidence identity

- Status: ACCEPTED_CURRENT
- Requirements: REQ-0001 through REQ-0006

Task Proof uses one strict runtime for Claim validation, source snapshots, evidence receipts, Review finalization, deterministic gates, immutable artifacts, and visual projections. Compatibility surfaces are adapters only. Content identity excludes clone-location noise but includes all bytes and metadata that can change the claimed implementation or evidence.

The runtime must fail closed on incomplete dirty fingerprints, receipt tampering, unsafe Git helpers, output-path escapes, stale snapshots, changed executable content, and artifact-set drift. A diagram remains a projection, never evidence or authority.
