# REQ-0004 — Deterministic, local, and safe operation

- Status: ACCEPTED
- Priority: P0
- Source: derived safety requirement for a reusable MCP
- Dependencies: none

## Statement

Task Proof shall operate locally without an embedded LLM or HTTP server, constrain repository and output paths, avoid returning patch bodies from Git snapshotting, escape untrusted content, and generate reproducible output from the same validated bundle.

## Acceptance criteria

1. Git snapshot workspace and resolved repository remain inside the MCP launch directory.
2. Snapshot captures exact revisions, changed paths, dirty state, and SHA-256 digest without returning patch text.
3. Output filenames are basenames; traversal, controls, and symlink output targets are rejected.
4. Identical bundles render byte-identical HTML.
5. HTML escapes untrusted text and includes required document metadata and a self-contained favicon.
6. The server performs no network, credential, remote-storage, or LLM operation.
7. Security and limitation boundaries are documented, including non-atomic two-file bundle writing until improved.
