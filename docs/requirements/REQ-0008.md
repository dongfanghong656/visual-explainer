# REQ-0008 — Discoverable and callable local Codex integration

- Status: ACCEPTED_LOCAL_CLI_VERIFIED
- Priority: P0
- Source: user report that other Codex tasks did not use the deployed visualizer and request to repair the local path only
- Dependencies: REQ-0004, REQ-0005

## Statement

The locally installed Visual Explainer Skills shall declare their MCP dependencies, use task-language discovery phrases, and have both the general renderer and Task Proof stdio servers registered in the active Codex configuration. Verification must distinguish configured, discoverable, exposed, and live-called states.

## Acceptance criteria

1. The general Visual Explainer Skill declares the `visual-explainer` stdio MCP dependency.
2. The nested Task Proof Skill declares the `visual-explainer-task-proof` stdio MCP dependency.
3. Both Skills include Chinese trigger phrases corresponding to their actual use cases without making routine prose/code work opt in to visualization.
4. Release verification performs a real three-tool general-renderer handshake and retains the eight-tool Task Proof handshake.
5. The packed artifact performs both handshakes from a clean installation.
6. The active local Codex configuration lists both installed-package servers as enabled.
7. A fresh Codex session can call the general renderer; an already-running desktop process is explicitly documented as requiring restart rather than being reported as hot-loaded.
8. ChatGPT web integration is outside this repair.
