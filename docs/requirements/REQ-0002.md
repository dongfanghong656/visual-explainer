# REQ-0002 — Independent reviewer using the same protocol

- Status: ACCEPTED
- Priority: P0
- Source: user request, 2026-08-25
- Dependencies: REQ-0001, REQ-0004

## Statement

A reviewer AI or human-assisted run shall load an author claim as an untrusted hypothesis, recollect exact scope, produce reviewer-owned evidence, evaluate every acceptance criterion and relevant change-logic claim, and render a corrected verdict using the same protocol.

## Acceptance criteria

1. Reviewer and author run IDs must differ.
2. Reviewer scope must match branch, base, head, dirty state, and digest; mismatch forces `stale`.
3. Every author acceptance criterion receives exactly one reviewer verdict.
4. `verified` and `contradicted` results require substantive reviewer evidence; Git snapshots and claim references are scope/context only and are insufficient by themselves.
5. `accepted` requires exact scope, reviewer Git-snapshot evidence, every criterion verified, exactly one verified check for every claimed event and invariant, and no critical or major discrepancy.
6. Verdict and corrected-completion combinations are mechanically consistent.
7. The review visual overlays checked mechanism events and preserves unreviewed claims as visibly unverified.

## Exclusions

Distinct run IDs provide procedural separation only. High-risk acceptance may require a different model, human, CI, or external system.
