# REQ-0005 — Reusable Skill/MCP distribution and upstream compatibility

- Status: ACCEPTED
- Priority: P1
- Source: user instruction to modify a strong existing project
- Dependencies: REQ-0001 through REQ-0004

## Statement

The extension shall be built as an additive fork of a capable existing visual-explanation project, preserve its general features, and expose Task Proof through discoverable Skill instructions, command prompts, MCP tools/resources, package metadata, examples, and documentation.

## Acceptance criteria

1. Upstream MIT license and authorship are preserved and the fork is clearly disclosed.
2. Canonical skill routes completion/review requests to Task Proof rather than free-form HTML.
3. `/task-proof` and `/task-proof-review` encode author/reviewer workflows and forbidden overclaims.
4. MCP exposes snapshot, claim validation/rendering, and review validation/rendering tools plus protocol/schema/example resources.
5. Package and Claude marketplace metadata use one candidate version.
6. Existing generic Visual Explainer tools remain registered.
7. A clean installation and real stdio client invocation pass before the project is called user-usable or released.
