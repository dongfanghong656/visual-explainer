# REQ-0001 — Evidence-gated author completion declaration

- Status: ACCEPTED
- Priority: P0
- Source: user request, 2026-08-25
- Parent objective: prevent implementing AI from converting its own narrative into unqualified completion
- Dependencies: REQ-0003, REQ-0004

## Statement

An implementation agent shall be able to create a structured, visual declaration of what it claims to have completed, what remains, why the change works, and what evidence supports each assertion, while being prevented from self-declaring independent acceptance or release.

## Acceptance criteria

1. The claim binds to repository identity, branch, base/head revision, dirty state, and dirty snapshot digest when applicable.
2. It contains stable task and acceptance-criterion IDs, Done/Doing/Next/Blocked lanes, risks, unknowns, and four independent artifact-status axes.
3. Every `claimed-pass` criterion and Done item references evidence in the registry.
4. `claimed-complete` is rejected when criteria are not all claimed-pass, Doing/Blocked remains, objective evidence is absent, or exact Git-snapshot evidence is absent.
5. Author output cannot use reviewer-only acceptance, `ACCEPTANCE_PASSED`, or self-declare `RELEASED`.
6. A deterministic HTML claim and JSON sidecar can be produced only after validation.

## Exclusions

The author claim does not prove semantic correctness, external validation, user acceptance, or release readiness.
