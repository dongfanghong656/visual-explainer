# Task Contract Authority Protocol 2.3 — Superseded

Protocol 2.3 is retained only for historical links. Its final gate still accepted caller-supplied derived status values too directly.

The current contract authority specification is:

- `CONTRACT_AUTHORITY_V2.4.md`
- `contract-authority.mjs`
- `task-contract.schema.json`
- `examples/task-contract.example.json`

Do not use Protocol 2.3 as an acceptance authority.
